The pin is a beta: the owner's call, 2026-11-02: the Hub's latest (RFM1Manager pins stable releases only).

GuitChordi is not a Felucca fork (no `felucca.c`, no `plat.h`, no `web/sim`), so neither sloop, plat nor felucca_web
fits it. The firmware is a portable application behind the `fw_*` calls (`firmware/app.c`: the input, the clock, the
UI and the 240 x 240 frame buffer, the settings snapshot) over a string engine (`dsp/engine.c`: fourteen voices of
Clipper's physical string model), which its browser simulator (`web/emu`) and its device build share, and a device
adapter (`firmware/fm1/main.c`) on X0X's Felucca HAL (`third_party/fm1-platform`) that only feeds the application.

- **The units:** `app.c` in `core_guitchordi.c` with the device's `-DGM_FM1=1` (its diagnostics strip and the
  "SAVE: RAM ONLY FOR NOW" line, as on a unit), `engine.c` in `guitchordi_engine.c`, both with build-fm1.py's
  `-ffp-contract=off -fwrapv -fno-strict-aliasing`. `fw_bank.h` (the chords, the 50 styles, the tunings' fret tables)
  is generated by `scripts/generate-firmware-bank.py` (~30 s) and copied to `build/gen`.
- **The adapter's work, redone on the ABI** (`core_guitchordi.c`'s header has the table): `audio()` is the audio ISR
  (one 128-frame half: `fw_keys`, `fw_button` by `button_map`, `fw_encoder` by `encoder_map`, `fw_master` on a
  change, `fw_render`, the device's own `gm_dac_sample`, then >> 8 to int16); frame / idle are the main loop (every
  50 ms: MASTER through `gm_master_reading`, the LEDs at their PWM duty, the frame); OCT- + OCT+ held 5 s is UBOOT
  (`exit(3)`). The input is debounced once per tick (a press at once, a release after 5 ms open).
- **SysEx:** the platform's `ota.c` on `common/sysex_ota.h` answers the M-UPGRADE identity with `identity.h`'s
  `FM-1_982` (provisional upstream: not reserved with the Hub). No performance MIDI in or out (main.c discards it).
- **Flash:** none written. The device writes only the update's staging area; SAVE keeps a RAM snapshot. The image is
  `common/nor.c`'s, never touched (`conformance.txt`: `flash none`).
- **Level:** the device's quiet-beta ceiling (~-22.5 dBFS at full scale), so the .rfm1 is as quiet as a unit.
- **Not emulated:** the boot guard (no failed boots here), the update session, the render-time diagnostics (the
  strip shows US 0 and L 0: no wall clock).
